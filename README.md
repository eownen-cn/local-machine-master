# 拾语 · English Grove

面向 A2 学习者的响应式英语学习 PWA。电脑为主要学习端，手机和平板支持同一套学习流程。

## 开发

需要 Node.js 22+（当前已在 Node 24 验证）。在 `/workspace/local-machine-master` 中运行：

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

生产构建含离线缓存，部署到 HTTPS 静态托管即可。开发模式不注册离线缓存。设备合成语音是否可离线取决于操作系统。

## 当前功能

- 学习首页、成长路径、素材书架、学习统计和设置
- 三题入门自查（不是正式 CEFR/雅思定级）
- 原创 A2 短篇听力、阅读理解、英译中参考自查、现在进行时微课
- 设备英语合成语音，支持变速与原文显示
- 本机 localStorage 进度、去重完成记录、复习时间安排、JSON 导出
- 一个语法复习示例卡，支持 10 分钟、1 天、3 天复习间隔
- 自适应桌面/平板/手机布局，键盘操作与弹窗焦点约束

## 当前边界与后续

本版本是可用的本地原型，非完整课程平台。所有内容为原创示例，不包含《新概念英语》原文、音频或广播转载。BBC、VOA、NPR 仅链接到官方来源；无隶属关系。

尚未接入：账号、跨设备同步、IndexedDB 课程存储、个人教材导入、真人分段音频、自动错题生成、逐词听写、真实学习计时、AI 点评、口语与写作。当前学习分钟按完成课程估算。

云同步计划使用 Supabase Auth + PostgreSQL：需要创建服务项目、设计数据库和行级访问权限后接入；不应在浏览器或 Git 中存放服务角色密钥。暂不要求用户提供任何密钥。

课程路线：A2 基础 → B1 → B2 → 雅思专项。教材上线前须取得适当使用授权。PWA 安装、语音和离线行为仍需 iPhone/iPad/Android 真机验证。
